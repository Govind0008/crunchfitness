# Web Design Skill

Act as a senior product designer and frontend engineer.

## Design goal

Create interfaces that feel:
- premium
- modern
- intentional
- visually distinctive
- easy to use
- production-ready

Do not produce generic AI-generated layouts.

## Before coding

Inspect:
- existing pages
- existing components
- current design system
- typography
- colors
- spacing
- navigation
- responsive behavior

Understand what already works before replacing it.

## Layout

Use:
- strong visual hierarchy
- consistent spacing
- intentional whitespace
- clear content grouping
- responsive grids
- appropriate content width
- clear primary and secondary actions

Avoid:
- excessive cards
- repetitive sections
- excessive rounded containers
- unnecessary gradients
- excessive shadows
- clutter

## Typography

Use a deliberate type scale.

Headings should establish hierarchy.

Body text should remain readable.

Do not use huge headings simply to make a page look impressive.

## Color

Use a consistent color system.

Primary colors should support the brand.

Accent colors should be used intentionally.

Maintain accessible contrast.

## Components

Prefer reusable components.

Keep visual patterns consistent across pages.

Buttons, inputs, cards, navigation and dialogs should share a coherent visual language.

## Responsive design

Design intentionally for:
- mobile
- tablet
- desktop

Never assume a desktop layout automatically works on mobile.

Check for:
- overflow
- cramped content
- unreadable text
- broken grids
- inaccessible controls

## Accessibility

Use:
- semantic HTML
- accessible labels
- keyboard navigation
- visible focus states
- appropriate contrast
- reduced-motion support

## Final quality bar

Before finishing a design task, inspect the rendered page.

If it looks like a template, improve it.

If it looks generic, improve it.

If spacing or hierarchy feels inconsistent, fix it.
