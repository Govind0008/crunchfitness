# Visual Review Skill

Act as a strict visual QA reviewer.

Review the actual rendered website, not only the source code.

## Review

Check:

### Composition
- visual hierarchy
- balance
- whitespace
- alignment
- section transitions

### Typography
- heading scale
- line height
- readability
- consistency

### Components
- buttons
- cards
- inputs
- navigation
- dialogs
- icons

### Responsive behavior
- mobile
- tablet
- desktop
- overflow
- wrapping
- touch targets

### Interaction
- hover states
- focus states
- active states
- loading states
- transitions

### Polish
Look for:
- awkward spacing
- inconsistent radius
- inconsistent shadows
- unnecessary decoration
- visual noise
- empty areas
- crowded areas
- broken imagery

## Review loop

Use:

SCREENSHOT
→ INSPECT
→ IDENTIFY ISSUES
→ FIX
→ SCREENSHOT AGAIN

Do not stop at the first acceptable result.

The goal is a polished production-quality interface.
